# javascript-calculator-precourse
## 기능 목록
### 입력
- [x] 문자열 입력받기
- [x] 공백("") 입력 시, 0으로 계산
- [x] 잘못된 값 입력 시, Error 처리 후 종료
  - [x] 구분자가 이상할 경우
  - [x] 양수가 아닐 경우

### 계산
- [x] 쉼표(,) 또는 콜론(:)을 기준으로 분리
- [x] 커스텀 구분자(// ~ \n)가 존재할 경우, 커스텀 구분자를 기준으로 분리
- [x] 분리된 문자열을 숫자로 변환
- [x] 합계 계산

### 출력
- [x] 출력 형식에 맞춰 결과값 출력
